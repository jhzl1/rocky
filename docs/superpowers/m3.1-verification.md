# M3.1 verification

Automated: `swift test` before the merge into `development` (see the plan's final run). The items below are the
design's Done-when lines, checked by hand on a personal repository.

## All changes (ALL-01…ALL-09)

- [ ] With 5 changed files, "All changes" in the Changes row shows them all in one center tab; a second click only
  selects the tab. With no changes the button is off, "No changes yet".
- [ ] The tab: `rectangle.stack`, "All changes" and the file count; it stays open and keeps its folds and its top row
  across tab and workspace switches and when closed and reopened.
- [ ] "Uncommitted · N" then "Committed · N"; each file's header stays at the top while its rows scroll, and the
  next one pushes it up.
- [ ] The name opens the file's diff tab (underline on hover); the rest of the header folds and unfolds it.
- [ ] Long lines scroll sideways together; the numbers, markers and headers stay at the left edge.
- [ ] Collapse all / Expand all; a large file stays at "Large diff · N lines" until Show.
- [ ] Binary, mode-only and pure-rename files show their caption and no chevron; notes "New file", "Deleted",
  "Renamed from …", "Mode 644 → 755".
- [ ] ⌥⌘↓ / ⌥⌘↑ scroll to the next / previous file with the accent bar; Return opens its diff tab; outside the tab they
  open diff tabs as before.
- [ ] While the agent edits, a file added above does not move the line being read.

## Review comments as a file (RVW-01, RVW-02)

- [ ] "Add all to chat" with 4 comments: a short bubble with the `[GITHUB]-PR-N-comments.md` chip (`text.bubble`,
  tooltip "Review comments on #N"); the agent reads the file and answers item by item. One comment: the singular text.

## Queued messages (QUE-01)

- [ ] Each queued message has "◷ Queued · ↑ Send now · ✎ Edit · ✕" under it, always visible; Edit is dimmed while the
  message box has content; a held queue reads "On hold until your next message".

## Paste

- [ ] A screenshot on the clipboard (Shottr, ⌘⇧4 with Control) pastes with ⌘V at once as `image.png`; text still pastes
  as text.
