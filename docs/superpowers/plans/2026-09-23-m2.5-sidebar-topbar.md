# M2.5 Workspace Shell Implementation Plan (sidebar, top bar, terminal panel)

**Status: done**, merged into `development` on 2026-09-23 (`b87be7b`). The manual checklist is still open: `docs/superpowers/m2.5-verification.md`.

> **Execution:** task by task. Tests are written with each change and run once, in Task 10 (global rule `## Tests` in `~/.claude/CLAUDE.md`). As in M2, rebuild and relaunch after every task (`scripts/make-app.sh`, then `open build/Rocky.app`) and commit only when the user asks. This plan gives decisions, files, public interfaces, required behavior and the tests to write. It does not carry the code: the implementer writes it.

**Goal:** Rocky's sidebar, top bar, tabs and terminal panel match the approved design; every clickable element shows the pointing hand; spinners turn smoothly with no per-frame work in the app; new chat rows enter softly; live agent activity shimmers instead of spinning.

**Visual and behavioral source of truth:** `docs/superpowers/design/2026-09-23-sidebar-topbar.html`. Open it in a browser. RockyUI gets new theme tokens, shared button styles, a Core Animation spinner, a shimmer text view, a custom sidebar list, a one-row top bar, and a custom chat/panel split.

**Spec:** `docs/superpowers/specs/2026-09-22-rocky-design.md`, milestone M2.5 (visual design) and Section 1 (energy). What M2 built, including every UI change made during it: the section "Changes during implementation" of `docs/superpowers/plans/2026-09-23-m2-terminal-scripts-env.md`.

## Decisions

Taken with the user on 2026-09-23:

- **Scope:** sidebar, top bar, tabs, terminal panel, and the motion of the chat. Out: diff stats in the rows (future git status module, `OUT-01`), pull request glyphs (M3, `OUT-02`), the changes panel (M3, `OUT-03`). The mock draws the diff stats only behind its "Future: diff stats" toggle.
- **Pointing hand on every clickable element** (`CUR-01`), a deliberate departure from the macOS convention.
- **The new spinner replaces `CircularProgress` everywhere** and turns **smoothly and continuously** (`MOT-01`). A stepped version was rejected: "la animación del circular no es fluida. Eso no debe ser así en el app".
- **New chat rows fade in and rise** (`MOT-02`).
- **Live activity shows its label with a shimmer instead of a spinner** (`MOT-03`).
- **Unread state lives in memory** (`ROW-04`).
- **A global settings button** in the sidebar footer opens the existing Settings window (`SB-08`).
- **No "new workspace" button in the sidebar top row**: its compose icon read as "new conversation" (`SB-01`).
- **The terminal panel is part of this redesign** (`TERM-01`…`TERM-07`).

Taken in this plan. Change them here, not during implementation:

- **Custom sidebar list** (`ROW-06`): `ScrollView` + `LazyVStack`, not `List(selection:)`, whose selection paints the system accent.
- **Custom chat/panel split** (`TERM-01`): not `VSplitView`, whose divider AppKit draws and which today is swapped for a `VStack` when the panel folds, so the height is lost and folding cannot animate.
- **Neutral selection everywhere**: panel tabs lose the accent fill (`TERM-02`); the accent is for unread and focus only.
- **Process dots in three states** (`TERM-03`): running, done, failed. A failed Setup no longer looks finished.
- **No state text at the right of the panel bar** (`TERM-02`, `TERM-03`): "Running" there was not clear, because it sat far from the tab it described (user feedback). The state shows on the tab's dot and tooltip, and as the last line of a finished process's terminal.
- **One control in the empty panel bar** (`TERM-04`): "New terminal" replaces a dead "Terminal" label plus a "+".
- **The live row reads "Working"**, not "Thinking" (`MOT-03`): `ThoughtRow` already uses "Thinking" for the agent's thoughts.
- **Entrance keys** (`MOT-02`): a key per row that survives regrouping, so a tool row joining "N tool calls" does not animate again, and the reply footer can fade in when its turn ends.
- **Spinner on Core Animation** (`MOT-01`), not `TimelineView(.animation)`.
- **Title bar height** (`WIN-01`): an empty toolbar in `.unifiedCompact` style; fallback in the requirement.
- **Workspace title** (`ROW-02`): oldest open titled conversation, from one store query at launch.
- **Error state** (`ROW-03`): a new `ChatSessionModel.failure` (an explicit stop also becomes `.stopped`), or a Setup that exited non-zero.
- **Needs you** (`ROW-03`) covers both `pendingPermission` and `pendingQuestion`.
- **Monogram color** (`SB-03`): FNV-1a of the repository id, never `hashValue`.
- **Folded repositories** persist in `@AppStorage("foldedRepoIds")`; panel height in `@AppStorage("terminalPanelHeight")`.
- **Search** is an inline filter, not a command palette.

## Global constraints

- macOS 15 minimum, Swift 6 language mode. No new dependencies.
- **Zoom:** every size in the spec is at 100 %. Text through `Font.rocky`, text- and icon-holding sizes through `Zoom.shared(_:)` (`TOK-02`). Title bar height H is AppKit's and does not scale.
- Energy (spec Section 1): no timers that poll. The spinner animates in the render server; the shimmer runs only on live rows, capped at 30 fps; both pause while the window is not key and stop with Reduce Motion.
- Menus: Rocky draws its own (`MenuPresenter`, `MenuButton`, `MenuItem`, `rockyContextMenu`); no SwiftUI `Menu` or `.contextMenu` (M2 rule).
- All code, comments, identifiers and UI copy in English.
- Commits: Conventional Commits, lowercase imperative, no `Co-Authored-By` or AI attribution line. Never `--no-verify`.
- Shell: `bat`, `eza`, `rg`, `fd`, `sd` (this machine blocks `cat`, `ls`, `grep`, `find`, `sed` in agent shells).
- Manual tests on personal repos only (`~/Documents/dev/personal/rocky`).

## Review Focus

1. No per-frame work in Rocky's process while spinners turn (Instruments, Task 10; `MOT-01`).
2. History never animates; scrolling never replays an entrance; a tool row joining a group does not animate again. Pinned by `ChatEntranceTests`.
3. The state priority is exactly needs you › error › working › unread › idle. Pinned by `WorkspaceStatusTests`.
4. Unread is set only for turns that end in a workspace that is not selected, and cleared on selection. Pinned by `AppModelTests`.
5. An explicit stop is not an error. Pinned by `ChatSessionModelTests`.
6. A repository's monogram color is the same on every launch. Pinned by `RepoMonogramTests`.
7. Folding the panel never stops a terminal or script; switching workspaces never animates the panel. Manual items 6 and 7.
8. Every clickable element shows the pointing hand: the `rg` check in `CUR-01` plus manual item 1.

### Task 4: Workspace status, unread and titles

**Requirements:** `ROW-02`, `ROW-03`, `ROW-04`.
**Files:** `Sources/RockyKit/App/WorkspaceStatus.swift` (new), `Sources/RockyKit/Chat/ChatSessionModel.swift`, `Sources/RockyKit/App/AppModel.swift`, `Sources/RockyKit/Store/RockyStore.swift`, `Tests/RockyKitTests/WorkspaceStatusTests.swift` (new), `Tests/RockyKitTests/ChatSessionModelTests.swift`, `Tests/RockyKitTests/AppModelTests.swift`, `Tests/RockyKitTests/RockyStoreTests.swift`.

```
public enum WorkspaceStatus: Equatable, Sendable {
  case needsYou, failed(String), working, unread, idle     // pullRequest, merged come later (OUT-02), before idle
  public static func resolve(needsYou: Bool, failure: String?, working: Bool, unread: Bool) -> WorkspaceStatus
}
ChatSessionModel
  public private(set) var failure: String?
  public var onTurnEnded: (@MainActor () -> Void)?
AppModel
  public private(set) var unreadWorkspaceIds: Set<String>
  public private(set) var workspaceTitles: [String: String]
  public func status(workspaceId: String) -> WorkspaceStatus
  public func title(for workspace: Workspace) -> (text: String, isFallback: Bool)
RockyStore
  public func conversationTitles() throws -> [String: String]   // workspace id → title of its oldest open titled conversation
```

It must:
- `failure` is set on the error paths only (where the state becomes `.stopped(Self.describe(error))`) and cleared when the chat starts again or a turn starts. `stop()`'s `.stopped("Stopped")` leaves it nil.
- `onTurnEnded` is called where the state goes from `.running` to `.ready`.
- `AppModel` sets `onTurnEnded` on every chat it creates: if the chat's workspace is not `selectedWorkspaceId`, insert it into `unreadWorkspaceIds`. Changing `selectedWorkspaceId` removes the new selection (`didSet`).
- `status(workspaceId:)`: needs you = any chat of the workspace has `pendingPermission` or `pendingQuestion`; failure = a chat's `failure`, else a Setup session that exited non-zero ("Setup exited with N. See the Setup tab."); working = `isAgentWorking`; unread = the set.
- `workspaceTitles` loads from `conversationTitles()` with the rest of the model, and updates where a conversation's title is saved and when a conversation closes.

Tests:
- `WorkspaceStatusTests.priorityOrder`: every pair of states resolves to the one listed first in `ROW-03`.
- `ChatSessionModelTests.explicitStopIsNotAFailure` and `agentExitSetsFailure` (the fake agent exiting with 3).
- `AppModelTests.turnEndingInAnotherWorkspaceMarksItUnread`, `selectingAWorkspaceClearsUnread`, `turnEndingInTheSelectedWorkspaceMarksNothing`, `titleFallsBackToTheWorkspaceName`, `failedSetupIsAnError`.
- `RockyStoreTests.conversationTitlesPickTheOldestOpenTitledConversation`: closed and untitled conversations are ignored.

Commit `feat(kit): add workspace status, unread and titles`.

## Known risks

- **Title bar height** (`WIN-01`) is not verified: the compact toolbar approach may not give 38 pt or may fight `.hiddenTitleBar`. The fallback is in the requirement; keeping 28 pt is acceptable.
- **`appearsActive`**: confirm the environment value on macOS 15 with the Xcode in use; otherwise use `controlActiveState` or window key notifications.
- **Custom split and SwiftTerm:** resizing the panel resizes the terminal; check that `TerminalHostView` reflows without flicker while dragging. If it does, resize the terminal on drag end only.
- **Entrance and scroll pinning:** the 6 pt rise could fight `defaultScrollAnchor(.bottom)` and the scroll-to-bottom `onChange`s. If rows jitter, keep the opacity and drop the offset, and note it below.
- **Shimmer cost:** 30 fps per live row, expected at most two or three at a time; measure it in Task 10.
- **Code drift after M2:** `RockyMenu`, `AppModel`, `ChatSessionModel`, `WorkspacePanelView` and `Zoom` were changing while this plan was written. Re-read the Preconditions symbols first.
