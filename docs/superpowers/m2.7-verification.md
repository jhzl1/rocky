The merge had two conflicts, and both kept both sides:
- `ChatSessionModel`: the interrupted mark and CMD-08's queue comment.
- `ChatView`: Esc for a focused terminal, the repository settings and the command popup.

It also brought over M2.6's remaining blocking work: one `@MainActor` fixture and `FileTabView`'s file read, which now
use `Task.blocking`.

The fixes found on the way are recorded in the plan's "Changes during implementation":
- Lost terminal output: the cooperative pool was starved by blocking git work, so `DispatchIO` never read. Fixed
  with `Task.blocking` on dedicated threads.
- A `Process.waitUntilExit()` that never returned (the serial hang).
- A SIGKILL fallback on a Stop right after a start.

Before the merge, the suite ran green three times in parallel (353 tests, about 1.8 s) and once serially (14.2 s).
